# Warehouse Gudang (Testing) - Login + Dashboard + Modul

Semua halaman ini **statis** (tanpa database) dan menggunakan **localStorage**.

## Cara menjalankan di Chrome
1. Buka folder ini: `c:/Users/USER/Desktop/web_test`
2. Klik dua kali file **`index.html`**
   - atau dari Chrome: buka `file:///.../web_test/index.html`

## Akun login default (untuk testing)
- username: **admin**
- password: **admin123**

## Modul
- `dashboard.html` : menu pilihan
- `warehouse.html` : CRUD barang (tambah / edit / hapus)
- `data-lain.html` : contoh data lain (CRUD sederhana)

## Catatan
- Data tersimpan di `localStorage`, jadi tetap ada saat refresh di browser yang sama.
- Untuk demo, tidak ada database/backend.
